# Why NH3

### 1. **Fertilizer Production**

- **Primary use**: Ammonia is the main ingredient in many fertilizers (like urea and ammonium nitrate).
- **Why**: It provides essential nitrogen for plant growth, making it crucial for **global food production**.

### 2. **Chemical Manufacturing**

- **Feedstock for other chemicals**: Used to produce chemicals like **nitric acid**, **hydrazine**, and **ammonium sulfate**.
- **Why**: It's a building block for a wide range of industrial chemicals.

### 3. **Refrigeration**

- **Industrial cooling**: Ammonia is used as a coolant in large refrigeration systems.
- **Why**: It’s efficient and widely used in **food processing** and **cold storage** due to its excellent heat absorption properties.

# Understanding

- **Docker**: The containerized environment in which the Kafka software is running.
- **Kafka Broker**: The service running within the Docker container, responsible for managing the communication between producers and consumers, and handling the Kafka topics.
- **Topic**: A Kafka concept that serves as a stream or category for organizing messages. In this case, the topic is receiving data generated by the bot simulation.
- **Producer**: The bot, which acts as the data producer by sending events or messages to Kafka topics.
- **Consumer**: The frontend application (currently in the console) that consumes or reads data from Kafka topics.
- **Alerting Mechanism**: On the consumer side, thresholds are monitored, and if the data goes beyond specified limits, an alert is triggered.

Kafka and Zookeeper Interaction: When you run Kafka in Docker, it will internally connect to Zookeeper for cluster management and coordination. Zookeeper will manage the metadata, partition leadership, replication, and other critical tasks. You don't need to manually import or reference Zookeeper unless you are interacting with it directly (e.g., for configuration or cluster management).
